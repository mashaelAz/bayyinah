# مطابقة معايير التحكيم النهائي

| المعيار | الوزن | ما في بيّنة | ما يكمله الفريق خلال 4–6 أكتوبر |
|---|---|---|---|
| جودة الحل التقني وتوظيف الذكاء الاصطناعي | 25% | OCR عربي مع تحسين الصورة، فصل المتن عن الإضافات، مطابقة بأربعة مستويات، بصمة النص، بدائل للمصدر (الكتب الستة 34,108 أحاديث، ونص المصحف 6236 آية)، 51 اختبارًا آليًا | تشغيل مجموعة الاختبار 3 مرات وتوثيق ثبات النتائج |
| تحقيق النفع وفق معيار نجاح المسار | 20% | تصحيح عملي: النص الصحيح بلفظ المصدر وبطاقة مصحّحة جاهزة للنشر بدل البطاقة الخاطئة؛ خمس حالات تميّز بين ما تؤيده المصادر وما يحتاج تحققًا أو إحالة؛ المصدر وحالة الدليل ظاهران وقابلان للتتبع | قياس مقارن: زمن الوصول للحكم يدويًا مقابل بيّنة على 10 مستخدمين |
| الموثوقية والسلامة العلمية | 15% | الحكم منقول حرفيًا، لا «موضوع» مكان «لم نعثر»، امتناع وإحالة، عرض كل الأحكام المتعارضة، مصادر من الحزمة العلمية | مراجعة شرعية لنتائج مجموعة الاختبار |
| الابتكار والقيمة المضافة | 15% | من لقطة شاشة إلى حكم موثق دون معرفة بعلم الحديث؛ بصمة النص تكشف تحريف اللفظ | المقارنة ببحث يدوي في محرك عام |
| تجربة المستفيد والتواصل والإتاحة | 10% | ست لغات مع اتجاه RTL/LTR، تصميم للجوال، تنبيه عند ضعف قراءة الصورة، «ماذا تفعل الآن؟» عند الفشل، تركيز لوحة المفاتيح | اختبار سهولة الاستخدام مع 5 مستخدمين وتسجيل التحسينات |
| واقعية التشغيل والاستكمال | 10% | يعمل على استضافة مجانية؛ القراءة في المتصفح؛ لا قاعدة بيانات؛ تكلفة تشغيل شبه صفرية | خطة: اتفاق مع الدرر، تطبيق جوال، إضافة واتساب |
| وضوح العرض وإتاحة التحقق | 5% | مسار الدليل في كل نتيجة، رابط المصدر، `/api/health`، وثائق في `docs/` | عرض 5 دقائق وفيديو دقيقتين |

## معيار نجاح المسار الرابع (نصًا من دليل المشارك)

> هل حسّن الحل دقة الوصول إلى المعرفة أو التحقق منها، وأظهر المصدر وحالة الدليل بصورة واضحة وقابلة للتتبع، وميّز بين ما تؤيده المصادر وما يتطلب مزيدًا من التحقق أو الإحالة؟

| جزء المعيار | في بيّنة |
|---|---|
| دقة الوصول إلى المعرفة | المستخدم يصل للرواية من لقطة شاشة، ومطابقة الألفاظ تكشف الرواية الصحيحة حتى مع التحريف |
| إظهار المصدر وحالة الدليل | بطاقة الحكم: المحدّث، الكتاب، الرقم، الرابط، والحكم حرفيًا |
| قابلية التتبع | مسار الدليل خطوة بخطوة في كل نتيجة |
| التمييز بين المؤيَّد وما يحتاج تحققًا | حالات واضحة للأحاديث والآيات وأقوال العلماء، مع إحالة وأزرار عمل عند الحاجة |

## المعيار العلمي الملزم في الحزمة

| البند | في بيّنة |
|---|---|
| الموثوقية والإسناد | لا حكم دون مصدر ورابط؛ النص الشرعي مفصول بصريًا عن الشرح |
| التمييز بين القطعي والاجتهادي | الأحكام المختلفة تُعرض كلها منسوبة لأصحابها دون ترجيح |
| عدم الاستقلال بالفتوى | لا توجد دالة تحكم على الحديث؛ إخلاء مسؤولية في كل نتيجة |
| مقاومة الهلوسة | امتناع وإحالة عند ضعف المطابقة؛ المساعد اللغوي لا يُقبل منه لفظ غير موجود في النص المدخل |
| الجودة الدعوية | خطاب محترم، شرح مبسط لنسبة المطابقة، إرشاد عملي عند الفشل |
| الترجمة والتوطين | ست لغات؛ متن الحديث وحكمه بالعربية دائمًا؛ مصطلحات وفق الجمهرة |
| الشفافية | تصريح بأنها أداة مدعومة بالذكاء الاصطناعي فوق لوحة التحقق |
| الخصوصية | الصورة لا تُرفع؛ لا حسابات؛ السجل في المتصفح فقط |

## مطابقة ملف الفكرة المسجّل («بيّنة»، مسار أدوات المعرفة والتحقق)

| ما ورد في ملف الفكرة | في الموقع |
|---|---|
| محرك تحقق وإسناد لصنّاع المحتوى والمعرّفين بالإسلام | الفئة مذكورة في الواجهة، والواجهة بست لغات للمعرّفين |
| يحلل نصوص وتصاميم الوسائط الدعوية (صورة أو نص) | رفع صورة مع OCR وتحسين الصورة، أو لصق النص |
| الأحاديث والآثار | البحث في الموسوعة الحديثية يشمل الآثار، مع تنبيه عند تصنيف النص أثرًا |
| استخراج الكلمات مع إمكانية تصحيحها | النص المستخرج يُعرض قابلًا للتعديل قبل البحث |
| مطابقة العبارة مع نصوص موثقة | مطابقة بأربعة مستويات مع الدرر السنية |
| المخرجات: موثق / لم يرد بهذا اللفظ / ضعيف أو غير ثابت / يحتاج تثبت | «ورد بهذا اللفظ» / «ورد بلفظ مختلف» / «لم يرد بهذا اللفظ» / «يحتاج إلى تثبّت»، مع شارة درجة ملوّنة (ضعيف بالأحمر) |
| النص المطابق بجانب النص المدخل | عرض جنبًا إلى جنب + بصمة النص |
| الدرجة بشارة واضحة | شارة «حكم المحدّث» بجانب الحالة |
| المرجع: رابط أو نص كامل، المصدر وبيانات التخريج | المحدّث والكتاب والرقم ورابط المصدر (التخريج المفصل غير متاح في خدمة الدرر، ولا نؤلّفه) |
| الأثر: تقليل وقت البحث، الحد من نشر غير الدقيق | قياسه في اختبار أيام التحدي؛ التصحيح والبطاقة المصحّحة للنشر بدل الخاطئة |
