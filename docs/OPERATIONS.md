# خطة التشغيل والتكلفة والصيانة

تجيب عن متطلب المستوى 5 في معيار قابلية الاستمرار: «خطة تكلفة وصيانة واضحة، ومسؤوليات محددة، وبديل للاعتماد الحرج».

## 1. التكلفة التشغيلية

| البند | الخيار الحالي | التكلفة |
|---|---|---|
| الاستضافة | Vercel (الخطة المجانية) | 0 |
| البحث في المصدر | الدرر السنية من متصفح المستخدم، والكتب الستة على خادم بيّنة | 0 |
| القراءة الضوئية | Tesseract.js داخل المتصفح | 0 (لا خادم) |
| تخزين بيانات المستخدم | لا يوجد؛ السجل في جهاز المستخدم فقط | 0 |
| المساعد اللغوي (اختياري) | Claude Haiku، لفصل المتن فقط | تقريبًا أقل من دولار لكل 1000 تحقق، ويعمل الموقع كاملًا بدونه |
| القراءة بالذكاء الاصطناعي (اختياري، بضغط المستخدم) | Google Gemini (الحصة المجانية) | 0 ضمن حدود الحصة اليومية |
| بديل مدفوع للقراءة (غير مفعّل) | Claude Haiku Vision | نحو دولارين لكل 1000 صورة، بالدفع حسب الاستخدام لا اشتراك |
| النطاق (اختياري) | اسم نطاق خاص | نحو 50 ريالًا سنويًا |

العمليات الثقيلة (القراءة الضوئية والبحث) تجري في متصفح المستخدم، فلا ترتفع التكلفة بزيادة المستخدمين.

**كل التشغيل الحالي مجاني.** والذكاء الاصطناعي إضافة لا أساس: المنصة تعمل كاملة بدونه. والقراءة بنموذج الرؤية لا تُستدعى إلا عند ضعف القراءة المجانية وبضغط المستخدم، فتبقى التكلفة صغيرة ومتناسبة مع الاستخدام الفعلي.

**عند تجاوز الحصة المجانية:** إذا بلغ الاستخدام حدّها اليومي يرى المستخدم تنبيهًا بتعذّر القراءة بالذكاء الاصطناعي، ويكمل بالقراءة المجانية أو بكتابة النص، ولا يتوقف الموقع.

**بدائل عند الحاجة:** نموذج رؤية مفتوح المصدر على خادم خاص، أو خدمة قراءة سحابية بحصة مجانية شهرية، أو تمويل الاستخدام من جهة دعوية شريكة أو منحة.

## 2. الاعتماد الحرج وبدائله

الاعتماد الحرج: **الموسوعة الحديثية بالدرر السنية**.

| الترتيب | الطريقة | متى تُستخدم |
|---|---|---|
| 1 | من متصفح المستخدم مباشرة | الوضع الطبيعي |
| 2 | عبر خادم بيّنة (`/api/dorar`) | إذا مُنع الطلب في المتصفح |
| 3 | متون الكتب الستة على خادم بيّنة (34,108 أحاديث بأرقامها وحكم الألباني على السنن) + نسخة مخزنة من سجلات الدرر | إذا تعذّر الاثنان؛ ويُنبَّه المستخدم بمصدر النتيجة |
| 4 | «جسر الدرر» الاختياري | للتحقق الأعمق إذا لم يوجد النص في الكتب الستة |
| 5 | «تعذر الوصول إلى المصدر» | إذا تعذرت المصادر كلها؛ لا نصدر نتيجة غير موثقة |

**الأثر:** حجب الدرر لم يعد يوقف المنصة؛ أغلب الأحاديث المتداولة الصحيحة في الكتب الستة، وما ليس فيها يأخذ نتيجة واضحة («لم يرد بهذا اللفظ في الكتب الستة») مع بطاقة تصحيح.

**تم:** أرسل الفريق طلب إذن رسمي إلى الدرر السنية (3 أكتوبر 2026) للسماح لخادم المنصة بالوصول إلى واجهة الموسوعة أو تزويدنا بطريقة وصول معتمدة، مع الالتزام بنسبة كل نتيجة إليها وعدم تخزين الموسوعة.

**على المدى المتوسط:** طلب إذن رسمي من الدرر السنية بواجهة برمجية أو نسخة مرخّصة، ثم فهرستها في قاعدة متجهات (مثل Supabase pgvector) لتحسين اكتشاف الألفاظ البعيدة، مع بقاء كل حكم منسوبًا لسجله.

**مصادر إضافية بعد موافقة أصحابها:** المكتبة الشاملة، وجمهرة، وموقع الشيخ ابن باز لأحكام الأحاديث المشتهرة.

## 3. المراقبة

- `/api/health` حالة الموقع.
- `/api/health?dorar=1` يختبر الاتصال بالدرر ويُظهر سبب الفشل.
- صفحة `/eval` تُشغَّل أسبوعيًا للتأكد من أن المصدر لم يغيّر شكل بياناته.

## 4. المسؤوليات

| المهمة | المسؤول | التكرار |
|---|---|---|
| قيادة المشروع والتواصل مع المصادر | شهد المالكي | مستمر |
| صيانة الكود والنشر | مشاعل العنزي | عند كل تحديث |
| تشغيل `/eval` وتحديث مجموعة الاختبار | ريماس روّاس | أسبوعيًا |
| مراجعة المحتوى الشرعي ونصوص الواجهة والترجمات | أميرة المسعودي | شهريًا وعند كل إضافة |
| مراجعة علمية خارجية لأمثلة العرض | مختص في الحديث (يُتفق معه) | قبل كل إطلاق |

> عدّلوا الأسماء حسب توزيعكم الفعلي.
