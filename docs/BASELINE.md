# نسخة البداية والإفصاح عن المكونات

وفق شروط التحدي (البند 8): «يمكن المشاركة بمشروع سابق بعد توثيق حالته والإفصاح عن مكوناته وحقوق الغير؛ ويُقيّم الإنجاز الجديد خلال أيام التحدي من 4 إلى 6 أكتوبر 2026م فقط».

## نسخة البداية

نسخة البداية هي **آخر commit في هذا المستودع بتاريخ سابق لـ 4 أكتوبر 2026**. أي commit بعده هو إنجاز أيام التحدي، ويظهر بتاريخه في سجل git:

```bash
git log --format="%h %ad %s" --date=iso
```

## ما تحتويه نسخة البداية

| المكوّن | الملفات |
|---|---|
| محرك التطبيع وفصل الإضافات وتصنيف النص | `lib/arabic/` |
| محرك المطابقة وبصمة النص | `lib/matching/` |
| الاتصال بالدرر السنية (متصفح، خادم، نسخة مخزنة) | `lib/providers/` |
| التحقق ومسار الدليل والتصحيح | `lib/verify.ts`، `lib/correction.ts` |
| القراءة الضوئية | `lib/ocr/` |
| الواجهة بست لغات | `app/`، `components/`، `lib/i18n/` |
| الاختبارات | `tests/` |
| التوثيق | `docs/` |

## الحقوق

- الشفرة من إعداد فريق بيّنة، بمساعدة أداة الذكاء الاصطناعي Claude (Anthropic) في الكتابة والترجمة، وقد راجعها الفريق واختبرها. نُفصح عن ذلك التزامًا بمنع تقديم المخرجات الآلية على أنها مساهمة بشرية خالصة.
- لا توجد قيود لصاحب عمل أو جامعة أو ممول على مساهمات الأعضاء (يقرّ بها كل عضو في المنصة).
- مكونات الطرف الثالث وتراخيصها في `docs/TOOLS_AND_LICENSES.md`.
- البيانات: سجلات منقولة من الدرر السنية للإحالة، ولا بيانات مستفيدين حقيقية ولا محادثات ولا مفاتيح سرية في المستودع.
